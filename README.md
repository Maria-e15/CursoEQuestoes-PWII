# 🎲 Curso de Probabilidade

## 📚 Sobre o projeto

Este projeto consiste no desenvolvimento de uma plataforma educacional utilizando **PHP**, como parte de uma atividade acadêmica realizada em trio.

A plataforma tem como objetivo ensinar conceitos básicos de **Probabilidade, conteúdo da disciplina de Matemática**, por meio de um curso com explicações teóricas e exemplos práticos.

Ao final do curso, os participantes poderão testar seus conhecimentos por meio de um quiz com **10 questões** sobre o conteúdo estudado.

## 🎯 Objetivos

- Desenvolver uma aplicação web utilizando PHP.
- Apresentar conceitos matemáticos de forma simples e didática.
- Avaliar o conhecimento adquirido por meio de um questionário interativo.

## 🧮 Conteúdo do curso

O curso poderá abordar os seguintes tópicos:

- Conceitos básicos de Probabilidade.
- Experimentos aleatórios.
- Espaço amostral e eventos.
- Cálculo de probabilidades.
- Exemplos práticos.
- União de dois eventos.
- Probabilidade da intersecção.
- Probabilidade condicional.

## 📝 Avaliação

Ao concluir o curso, o participante terá acesso a uma prova com **10 questões** relacionadas aos conteúdos apresentados.

A avaliação tem como finalidade verificar a compreensão dos conceitos estudados durante o curso.

## 🛠️ Tecnologias utilizadas

- **PHP** — desenvolvimento da lógica da aplicação.
- **HTML5** — estrutura das páginas.
- **CSS3** — estilização e organização visual.
- **Bootstrap 5** — estilização e organização visual.

## 🚀 Como executar o projeto

1. Instale um ambiente de desenvolvimento com suporte a PHP, como o [XAMPP](https://www.apachefriends.org/).
2. Clone este repositório ou faça o download dos arquivos.
3. Coloque a pasta do projeto no diretório `htdocs` do XAMPP.
4. Inicie o Apache pelo painel de controle do XAMPP.
5. Abra o navegador e acesse:

   `http://localhost/nome-do-projeto/`

6. Explore o curso e responda às 10 questões ao final do conteúdo.
